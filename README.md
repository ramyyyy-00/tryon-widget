# Try-On Widget (MVP) — زرار "جرّب المنتج" لأي متجر

إضافة بسيطة تتحط في أي موقع لبس: العميل يدوس **Try on**، تفتح الكاميرا، واللبس يظهر عليه مباشرة (بنفس فكرة Anywear).
الذكاء الاصطناعي بتاع **Decart AI** (الموديل `lucy-vton`). الإضافة دي مجرد الغلاف حواليه.

> **تنبيه صريح:** الكود ده اتكتب من توثيق Decart الرسمي لكنه **مش متجرّب على API حقيقي** (محتاج مفتاح). أول ما تشغّله ممكن تحتاج تعدّل حاجة صغيرة. شوف قسم "لو حاجة ما اشتغلتش".

## الملفات
```
server.js                  السيرفر: بيخبّي مفتاح Decart وبيدّي مفاتيح مؤقتة ويعدّ الجلسات
brands.json                قايمة البراندات المسموح لها (الموقع + حد الجلسات الشهري)
public/tryon-widget.js     السكريبت اللي البراند بيلصقه في موقعه
demo/index.html            صفحة تجربة فيها منتجين
.env.example               مكان مفتاح Decart
```

## التشغيل على جهازك
1. نزّل **Node.js 18 أو أحدث** (nodejs.org).
2. اعمل حساب على **platform.decart.ai** وخد **API key**.
3. انسخ `.env.example` باسم `.env` وحط المفتاح فيه:
   ```
   DECART_API_KEY=المفتاح-بتاعك
   ```
   **ماتبعتش المفتاح لأي حد ولا في أي شات، وماترفعش ملف `.env` على GitHub.**
4. افتح التيرمنال جوه الفولدر وشغّل:
   ```
   npm install
   npm start
   ```
5. افتح: **http://localhost:3000/demo/** ودوس **Try on** تحت أي منتج.
   (الكاميرا بتشتغل على `localhost` أو على موقع `https` بس.)

## إزاي براند يركّبها (سطر واحد)
في صفحة موقعه:
```html
<script type="module" src="https://سيرفرك/widget/tryon-widget.js"
        data-brand="اسم-البراند" data-lang="ar"></script>
```
وكل منتج يتعلّم بـ:
```html
<div data-tryon-image="رابط-صورة-اللبس" data-tryon-name="هودي رمادي"> ... </div>
```
- `data-lang` = `ar` أو `en`.
- `data-seconds` = مدة الجلسة بالثواني (الافتراضي 60).
- `data-tryon-prompt` (اختياري) = وصف مخصص للقطعة بالإنجليزي (20–30 كلمة: اللون والخامة والنقشة).

## لما تضيف براند جديد
في `brands.json` أضف:
```json
"brand1": { "name": "Brand 1", "origins": ["https://brand1.com"], "monthlySessionLimit": 300 }
```
- `origins` لازم تكون **عنوان موقعه بالظبط** (https وبدون / في الآخر).
- `monthlySessionLimit` بيحمي فلوسك: بعد العدد ده السيرفر بيرفض.
- عدد الجلسات الشهرية بيتسجل في `usage.json` (تقدر تحاسب البراند منه).

## التكلفة (حسب تسعير Decart وقت الكتابة)
حوالي **1.2$ للدقيقة** (2.4$ في الوضع السريع). الجلسة هنا مضبوطة على 60 ثانية، يعني **حوالي 1.2$ للجلسة**. سعّر الباقات على الأساس ده + هامش + رسوم تركيب. راجع الأسعار الحالية قبل أي عرض.

## قبل ما تبيعها لأي براند
- **اقرأ شروط Decart** واسأل: هل مسموح تدمج الموديل في منتج وتبيعه لعملاء؟ (ممكن يكون عندهم برنامج شركاء/وكالات.)
- **صور المنتجات:** لبس لوحده على خلفية بيضا، 512×512 على الأقل. الصور السيئة بتخلّي النتيجة وحشة.
- **الخصوصية:** الويدجت بيعرض رسالة موافقة قبل الكاميرا. براند عنده عملاء في أوروبا أو السعودية محتاج سياسة خصوصية مكتوبة.
- **جرّب على لبس حقيقي** (هودي، تيشيرت، جاكيت) وعلى إضاءات مختلفة قبل ما تعد حد.
- **السيرفر لازم يتنشر** (Render أو Railway أو Fly) على `https` عشان البراندات تستعمله. مش لازم دلوقتي.

## لو حاجة ما اشتغلتش
- **ماوصلش مفتاح للمتصفح / خطأ اتصال:** افتح الـ Console (F12) وشوف شكل الـ token اللي رجع. السطر `return t.apiKey ?? t.token ?? t.key ?? t;` في `tryon-widget.js` ممكن يحتاج يتغير حسب الحقل اللي Decart بترجّعه.
- **اسم الموديل:** لو اتغيّر، غيّره من `data-model="..."` أو من `CONFIG.model` في الويدجت.
- **تحميل الـ SDK:** بيتحمّل من `esm.sh`. للنسخة الجاهزة للبيع ثبّت رقم نسخة محدد أو ضمّه مع الكود.
- قارن بالمثال الرسمي: `github.com/DecartAI/tryon-examples` (مثال e-commerce).
